
## Most Important Suspect

Do not start by changing card transform math again.

First inspect the scroll/sticky containment chain. In the current app, `src/App.tsx` wraps the homepage shell with:

```tsx
<main className="relative z-10 w-full overflow-hidden ...">
```

That `overflow-hidden` ancestor is a strong suspect because sticky positioning often fails or changes behavior when an ancestor creates an overflow container. The `project-start` source shell used `overflow-x-clip`, not full `overflow-hidden`.

Likely first experiment:

```tsx
// src/App.tsx
<main className="relative z-10 w-full overflow-x-clip selection:bg-accent-primary/20 selection:text-accent-primary">
```

Then verify whether the stack actually sticks before making any further Framer Motion changes.
